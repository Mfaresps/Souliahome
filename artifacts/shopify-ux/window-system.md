# نظام نوافذ العمل — Shopify والحوارات المشتركة

التاريخ: 2 نوفمبر 2026

## الجرد

في نموذج نافذة الطلب المصور توجد 10 إجراءات مرئية: 6 إجراءات بأيقونات (طباعة، إغلاق، نسخ، واتساب، Vrobo، اتصال)، وإجراءان ثانويان (اعتراض العربون وفتح متابعة)، وإجراء تعليق، وإجراء أساسي لإضافة العربون. كانت الارتفاعات بين 32 و40 بكسل، مع حركات دخول مختلفة بين نافذة الطلب والتعديل والمتابعة والحوارات العامة.

الطبقة المشتركة في [window-system.css](../../frontend/public/window-system.css) تخدم نافذة الطلب، تعديل الطلب، إنشاء المتابعة، مسار التعليقات، الحوار العام، التأكيد المخصص، تفاصيل الفاتورة، وحوارات HTML الأصلية. التطبيق الحالي HTML وCSS وJavaScript؛ لذلك بقيت الطبقة في `frontend/public` بدل إنشاء حزمة React مستقلة.

## عقد المكوّن

| الجزء | العقد |
|---|---|
| حركة الدخول | 180 مللي ثانية، ارتفاع 10 بكسل مع ظهور تدريجي، بلا تكبير أو ارتداد |
| الحركة المخفضة | فتح وإغلاق فوريان عند `prefers-reduced-motion: reduce` |
| الإجراء الأساسي | `.ui-action.ui-action--primary` للحفظ أو إضافة بيانات |
| الإجراء الثانوي | `.ui-action.ui-action--secondary` للتنقل أو فتح مهمة |
| الإجراء الهادئ | `.ui-action.ui-action--ghost` لإضافة تعليق أو إجراء مساعد |
| زر الأيقونة | `.ui-action.ui-action--icon` مع اسم متاح لقارئ الشاشة |
| المقاس | 40 بكسل في المؤشر الدقيق، و44 بكسل على الأجهزة اللمسية |
| التركيز | حد واضح بلون العلامة؛ لا يعتمد على اللون وحده في الحالة المعطلة |

أزرار نافذة الطلب تستخدم أصناف المكوّن الجديدة مع أصنافها القديمة خلال الانتقال التدريجي. عند نقل نافذة أخرى، يُستخدم نفس العقد دون نسخ قيم الحركة أو المقاسات إلى ملف جديد.

على الهاتف تظهر الأصناف والدفع قبل الإجراءات المتخصصة في ترتيب القراءة والتنقل بلوحة المفاتيح، ويظل توزيع العمودين على سطح المكتب كما هو. هذا يضع بيانات الطلب وزر العربون في أول الشاشة.

## تحميل البيانات

يُرسم رقم الطلب والعميل والأصناف والدفع من بيانات القائمة الموجودة فور الفتح. قسم المتابعة وحده يعرض هيكل تحميل عند غياب بياناته؛ تُعرض البيانات المحفوظة مباشرة عند توافرها، وتتشارك النوافذ المتزامنة طلب شبكة واحدًا. فشل طلب المتابعة يترك نافذة الطلب قابلة للاستخدام ويُظهر إعادة المحاولة داخل القسم.

## التحقق

- لقطة [نافذة الطلب](order-window-1440.png) تُظهر جميع أنماط الإجراءات في حالة طلب بلا عربون.
- اختبار المتصفح يفحص ظهور بيانات الطلب قبل انتهاء جلب المتابعة، وطلب الشبكة الواحد، وحركة الدخول الموحدة، والتركيز، والإغلاق الفوري مع تقليل الحركة.
- مراجعة اللقطات على 1440 و768 و390 بكسل مع الوضع الداكن وحالة فشل التحميل.

## التبني والإصدارات

بدأ النقل بأزرار نافذة طلب حقيقية: الطباعة، الإغلاق، التواصل، فتح المتابعة، إضافة التعليق، وإضافة العربون. الخطوة التالية عند الانتقال إلى صفحة أخرى هي نقل أكثر نوافذها استعمالًا إلى الأصناف نفسها ثم حذف تنسيقها المكرر بعد التحقق البصري. تُراجع تغييرات المقاس أو التباين مع لقطات الهاتف وسطح المكتب واختبار لوحة المفاتيح. تُنشر هذه الطبقة مع التطبيق نفسه؛ لا توجد حزمة UI مستقلة تستدعي Changesets أو إصدارًا منفصلًا.
